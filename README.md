
# Student Assignment Tracker

## Project Description

Student Assignment Tracker is a web application designed to help students organize their school assignments and keep track of upcoming due dates.

Users can enter assignment information, save assignments, and view their assignments in an organized list.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Sprint 1 Goal

The goal of Sprint 1 is to allow students to create assignments, save them locally, and view their saved assignments in an organized list.

The application also includes basic input validation.

## Features

### Add Assignments
Users can enter:
- Assignment title
- Course name
- Due date
- Optional description

### View Assignments
Users can view their saved assignments, including their course names, due dates, and descriptions.

### Save Assignments
Assignments are saved using browser localStorage.

Saved assignments remain available after refreshing or reopening the application in the same browser, provided the browser's local storage is not cleared.

### Input Validation
Users must enter an assignment title and due date before saving an assignment.

## How to Run the Application

1. Download or clone this GitHub repository.
2. Open the StudentAssignmentTracker folder.
3. Double-click index.html to open it in a web browser.
4. The application will load automatically.

No additional software installation or configuration is required to run the application.

## How to Use

1. Enter an assignment title.
2. Enter the course name.
3. Select the assignment due date.
4. Enter an optional description.
5. Click "Add Assignment".
6. View the assignment under "My Assignments".
7. Refresh the page to confirm that the assignment remains saved.

## Known Limitations

- Assignments are saved only in the current browser's local storage.
- Assignments do not synchronize between devices.
- The application does not currently support editing or deleting assignments.
- A calendar view is not yet implemented.
- Assignment completion tracking is not yet implemented.
- Upcoming assignment recommendations are not yet implemented.
- Personal notes and ideas are planned for a future sprint.

## Future Improvements
